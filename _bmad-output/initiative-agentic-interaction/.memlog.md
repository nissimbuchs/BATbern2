- (direction) Owner round-table 2026-11-21 (Winston, Sally, Mary): intent in, confirmation out; pilot both speaker mail agent and organizer brief + chat; shrink cockpit to the max; generated UI on the fly; agent acts on behalf, learns from 60 past events, asks only when unsure. Source: architecture spine + its memlog.
- (requirement) R1 (AD-3, AD-10, AD-15): the agent acts only as one named principal of an allowlisted user, with that principal's rights; switching the agent off stops every agent action within one token lifetime, shown by a live switch-off during a run.
- (requirement) R2 (AD-4): a pilot speaker mails abstract and photo to the agent address and both land on their session with no organizer step; a mail failing sender authentication or from an ineligible sender reaches the organizers as today.
- (requirement) R3 (AD-5, AD-15): the pilot speaker gets the agent's answer in their profile language inside their Mail Center conversation, visible in the outbound log.
- (requirement) R4 (AD-11, AD-12, AD-16): a decision that needs the speaker reaches them as a one-tap card behind a mail link; opening the link changes nothing, confirming executes only the stored action.
- (requirement) R5 (AD-6, AD-7, AD-8): the agent carries out reversible actions and precedent-backed binding actions on its own and asks an organizer otherwise; mail to more than one non-organizer always waits for approval; every verdict names the past-event precedents it used.
- (requirement) R6 (round-table, AD-13): organizers receive a morning brief mail for the current event naming what needs attention, each item with an action they can take from it.
- (requirement) R7 (AD-11, AD-13): an organizer asks a question in chat and gets a generated view (table, chart, cards) built only from catalog components, and can act from it through the gate.
- (requirement) R8 (AD-13): the oversight console (activity feed, pending approvals, brief, chat) is the pilot organizers' home page; screens it replaces are hidden for them; no new organizer CRUD screen is added.
- (requirement) R9 (AD-7, AD-9): organizers see every agent action with its verdict, can overrule a pending or taken decision, and undo a reversible action.
- (requirement) R10 (spine operational envelope, round-table): the scripted personas (late speaker, wrong file, title change the day before, surprise co-speaker) each run end to end on production before the event, with expected outcomes checked against the decision log.
- (requirement) R11 (round-table): the pilot runs live at the next BATbern event with organizers as speakers, and a summary from the decision log is ready to present there.
