# Attendee Event History

> A logged-in attendee's personal list of the BATbern events they registered for and attended

> **Last Updated**: 2026-06-13

<span class="feature-status implemented">Implemented</span> — Epic 7.6

## Overview

Once an attendee has logged in (via "Continue with Google"), they get a simple dashboard listing the events they have a relationship with: the events they **registered for** and **attended**. It is the attendee-facing counterpart to the return channel the rest of this section opens up — a small, useful reason to be signed in.

## How it works

The dashboard is **attendee self-service**: a logged-in attendee opens their dashboard and sees the events tied to their account. There is no organizer triage involved — it simply reflects the attendee's own registration and attendance history.

```
Logged-in attendee  →  opens their dashboard
        ▼
Lists the events they registered for / attended
```

## What's in scope

- A logged-in attendee dashboard listing the events they registered for / attended.
