📱 The mobile strategy

Seven destinations don’t fit a phone tab bar (4–5 max is the platform norm), so the IA changes shape — it doesn’t just shrink.

1 · Bottom nav + “More”

The four day-to-day destinations live in the bottom bar — Cockpit, Speakers, Registrations, Communications. The three occasional ones (Publishing, Wrap-up, Settings) live behind ⋯ More, which opens a sheet. Badges/dots ride on the nav icons. Tap ⋯ More to see it.

2 · Cockpit is the answer to “what now?”

On a phone the cockpit matters more, not less — the organizer checks it on the train. Lifecycle collapses to a single Step 4/9 bar; attention tasks stack full-width; metrics go 2-up.

3 · Drag → tap-to-assign

Drag-drop is hostile on touch. In Speakers → Slots, tap an unassigned session, then tap a highlighted slot. Same model, thumb-friendly. Try it.

4 · Tables → cards

Registrations becomes a search box + stacked cards (the real app already does responsive cards), with row actions in an overflow menu.

5 · Lifecycle dimming holds

Wrap-up shows a 🔒 in the More sheet until EVENT_LIVE — same adaptive rule as desktop.
