Course Description

Hands-on instructor-led introduction to AI-assisted software engineering using Claude Code, the ELCAi Method, and the BMAD framework.

Morning: onboarding, installation, and tool orientation. Afternoon: live demonstration and guided exercises using real-world examples — from brainstorming through UX design to production-ready PRDs.

Objectives

AI-assisted development is transforming how we work across all roles — from business analysis to architecture to implementation. This instructor-led course provides the foundational skills to get started immediately.

Participants will learn:

  • How to install and configure Claude Code with the ELCAi extensions (company-specific templates, workflows, MCP integrations)
  • How the BMAD Method structures AI-assisted development into 4 phases with specialized agents
  • How to interact with AI agents conversationally to produce real deliverables (brainstorming reports, UX specs, PRDs)
  • Practical techniques for steering agent output — when to guide step-by-step vs. when to let the agent drive autonomously
  • The difference between quick-flow (single session) and full-path (multi-agent) approaches

By the end of the day, participants will have hands-on experience running BMAD workflows and will be able to apply them in their own projects.

Content

Morning — Onboarding & Foundations (3.5h)
  • Claude Code installation and setup (live, hands-on)
  • ELCAi Method overview: what it adds to BMAD (ELCA-specific templates, workflows, MCP servers)
  • BMAD Method fundamentals: 4 phases, 7 agents, artifact chain, workflow map
  • Live demo: activating an agent, running a workflow, reviewing output
  • Hands-on exercise: participants activate their first agent and run a basic workflow
Afternoon — Guided Exercises (3.5h)
  • Exercise 1 — Quick Flow: brainstorm partner enhancements and produce a PRD in a single session (Analyst Agent)
  • Exercise 2 — Full Path: multi-agent walkthrough of the Active Meeting Agenda example (Analyst → UX Designer → PM)
  • Review and discussion: comparing quick-flow vs. full-path output quality and when to use each
  • Q&A and applying learnings to participants' own projects

Basic understanding of software development lifecycle
No prior AI or BMAD experience required
