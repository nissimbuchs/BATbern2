| **Course Name** | ELCAi Agentic Engineering Basics — Self-Guided |
| **Course short description** | Self-paced introduction to AI-assisted software engineering using Claude Code, the ELCAi Method, and the BMAD framework. Participants work through interactive HTML training materials covering the full journey from brainstorming to production-ready specifications, at their own pace. |
| **Objectives** | AI-assisted development is transforming how we work across all roles — from business analysis to architecture to implementation. This self-guided course introduces the foundational tools and workflows that make this possible. Participants will learn: how to set up and use Claude Code as an AI engineering assistant; what the ELCAi Method adds on top of BMAD (company-specific templates, workflows, and MCP integrations); how to interact with specialized AI agents (Analyst, PM, UX Designer, Architect) to produce real deliverables; and the difference between quick-flow (single session) and full-path (multi-agent) workflows — when to use which. By the end, participants can confidently activate BMAD agents and run basic workflows in their own projects. |
| **Content** | - Introduction to the BMAD Method: 4 phases, 7 agents, artifact chain, workflow structure - Example 1 — Quick Flow: single-session brainstorm-to-PRD for small feature sets (Partner Enhancements) - Example 2 — Full Path: multi-agent, multi-session workflow across Phases 1-3 (Active Meeting Agenda) - Phase 1 walkthrough: Brainstorming with the Analyst Agent (Mary) — structured techniques, feature discovery, prioritization - Phase 2 walkthrough: UX Design with Sally, PRD creation with John (PM) — how agents synthesize prior artifacts - Phase 3 preview: Architecture with Winston, Epics & Stories — what comes next - Generated artifacts: brainstorming reports, UX specifications, PRDs — reviewing and understanding the output quality |
| **Prerequisites** | - ELCA laptop with Claude Code installed (see ELCAi onboarding guide) - Basic understanding of software development lifecycle (requirements, design, implementation) - No prior AI or BMAD experience required |
