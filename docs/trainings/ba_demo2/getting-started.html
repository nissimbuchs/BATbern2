One-Time Setup (Windows 11)

Install the tools you need — you only do this once

! Get Your Claude Code License First

Company compliance requires an Enterprise license for Claude Code. You must have this before you start.

  1. Go to the ELCA Manager Portal → Licenses
  2. Order a Claude Code Enterprise license
  3. You will need a Vertec project number where the license cost will be invoiced
  4. Wait for the license confirmation email before proceeding

⚠️ Do not use personal or free-tier accounts — only enterprise licenses are approved for company data.

You'll need admin rights for about 10 minutes. Open Make Me Admin from the Start menu and activate admin access before starting. You have one hour — more than enough.

1 Install Node.js (if not already installed)

BMAD requires Node.js v20+. Open UnigetUI and search for Node.js LTS, then click Install. Or use PowerShell:

> winget install OpenJS.NodeJS.LTS

Verify it's installed:

> node --version
# Should show v20.x.x or higher

2 Install Claude Code

Claude Code is the AI coding assistant that runs BMAD agents. Install it via npm (which comes with Node.js):

> npm install -g @anthropic-ai/claude-code

Verify it's installed:

> claude --version

The first time you run claude, it will ask you to log in with your Anthropic account. Follow the prompts — it opens a browser window.

3 Install BMAD into your project

Navigate to your project folder in PowerShell, then run the BMAD installer:

> cd C:\Users\YourName\Projects\my-project
> npx bmad-method install

The installer asks a few questions:

  • Which module? → Choose bmm (the standard Business Method Module)
  • Which tool? → Choose claude-code
  • Your name, preferred language, output folder → Follow the prompts

That's it. BMAD is now installed in your project. You can close Make Me Admin.

You're set up! You only do the above once per machine (steps 1-2) and once per project (step 3). From now on, you just open Claude Code and activate agents.
1

Opening the Tool

Three commands. That's all it takes.

1 Open PowerShell

Press Win + R, type pwsh (or powershell), and press Enter. You'll see a blinking cursor. That's your command line. Don't worry — you only need to type two things.

2 Navigate to your project and start Claude Code

Type the following and press Enter:

> cd C:\Users\YourName\Projects\my-project
> claude

Replace the path with your actual project folder. A prompt appears — it looks like a chat window in your terminal. You can type natural language, just like texting.

That's it. You're in. Claude Code is running. You can already ask it questions, and it will answer. But to unlock the real power, you'll activate an agent.
2

Activating Your First Agent

One slash command turns Claude into a specialized colleague

Agents are specialized personas. Instead of a generic AI, you get a focused expert with a structured workflow. Here's how to activate one:

/bmad-agent-bmm-analyst

Type that command and press Enter. The agent introduces itself and shows you a menu with numbered options. It looks something like this:

Mary (Business Analyst) reporting for duty!

[BP] Brainstorm Project — Guided ideation session
[DR] Domain Research — Explore a domain or industry
[PB] Product Brief — Create a 1-2 page strategic vision
[CH] Chat — Just talk with me

Type a code like BP or a keyword like brainstorm. That's how you talk to agents. They understand both.

The 5 Things You'll Type Most

Memorize these and you can work with any BMAD agent

1-9

A Number

Select a menu option. Type the number or the short code shown next to it.

C

Continue

Move to the next step. This is the single most common thing you'll type. The agent finishes a section, you review it, and type C to proceed.

yes

Approve

"yes", "ok", "looks good" — all mean the same thing. You're telling the agent to keep going with what it proposed.

no, X

A Correction

"no, change X to Y" or "merge these two" or "remove that part" — you're the boss. The agent adjusts.

why?

A Question

"why did you choose this?" or "explain more about X" — agents love questions. Asking makes the output better, not worse.

That's really it. Numbers to select, C to continue, yes to approve, corrections to redirect, questions to dig deeper. Everything else is just natural conversation.
4

What If Something Goes Wrong?

Short answer: nothing breaks. Here's the long answer.

The agent proposes something incorrect
→
Say "no, that's wrong because..." and explain. The agent will adjust immediately.
You want to go back to an earlier point
→
Say "let's go back to..." — agents track conversation context and can revisit any step.
You're confused about what to do next
→
Type /bmad-help — it analyzes your current state and shows you what step comes next.
The agent is doing too much at once
→
Say "stop" or "wait" — then redirect it to what you need. You control the pace.
You made a typo or gave wrong information
→
Just correct yourself in the next message. The agent adapts. No need to start over.
Bottom line: You cannot break anything. The agent doesn't judge. It doesn't get frustrated. It adapts to whatever you tell it. If you're unsure, just ask — "what should I do here?" works perfectly.

Four phases, each with a specialized agent, producing artifacts that chain together

Each phase has an agent. You activate one, work through its menu, produce an artifact, then move to the next.

Brainstorming → PRD → UX Spec → Architecture → Epics & Stories → Code
You don't need to do all phases. For small, well-understood features, the Quick Flow skips straight to what matters. For large, novel features, the Full Path gives you thorough coverage. BMAD adapts to you.

The best BAs aren't the ones who type the most. They're the ones who ask the right questions and push back when something isn't right. That's your superpower — the agent handles the rest.
