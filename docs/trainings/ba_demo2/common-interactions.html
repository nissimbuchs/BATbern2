How to Steer Your Agent

The micro-skills of working with BMAD agents. Print this page, bookmark it, or keep it open in a tab. These work with ANY BMAD agent — Analyst, PM, Architect, UX Designer, or Developer.

✔ Approving & Continuing

You want to...Type this
Accept and move onC  or  c
Approve a proposal"yes", "ok", "looks good"
Accept with a small note"yes, but also consider X"
Accept most, change one thing"good, but rename X to Y"
Skip a step entirely"skip this step" or C

✏ Correcting & Redirecting

You want to...Type this
Reject a proposal"no, instead do X"
Change something specific"change the name from X to Y"
Merge two things"merge epic 2 and 3"
Split something"split this into two: one for X and one for Y"
Remove something"remove the feedback feature from MVP"
Reorder priorities"move item 3 to the top"

? Asking for More

You want to...Type this
Get more detail"explain more about X"
See alternatives"what other options are there?"
Understand a decision"why did you choose this approach?"
Check dependencies"does this work with the existing dependencies?"
Validate something"does this cover all the requirements?"
Get a summary"summarize what we have so far"

⚙ Navigating the Workflow

You want to...Type this
See what's next/bmad-help
Get the menu againMH  or  "show menu"
Go deeper on a topicA  (Advanced Elicitation)
Get multiple perspectivesP  (Party Mode)
Leave the agentDA  or  "dismiss agent"
Switch to a different agentDA, then activate the new one

⚡ Power Moves (for when you're comfortable)

You want to...Type this
Rename things to match your project"call these epics 8.1, 8.2 instead"
Add domain context"remember, we already have X from Epic 8"
Challenge the agent"I disagree — here's why..."
Point out a gap"you forgot that custom items also need X"
Set constraints"keep this to 4 epics maximum"
Let the agent drive"drive autonomously, I'll review at the end"
Remember: These are all natural language. You don't need to memorize exact phrasing. "nah, do X instead" works just as well as "no, instead do X". The agent understands intent, not just keywords.
