Prerequisites & Setup

What you need before starting either course

For Both Formats

RequirementDetails
Claude CodeInstalled and working. Run claude --version to verify.
BMAD MethodInstalled in your project. The /bmad-agent-bmm-analyst command should work.
A project folderAny project with a .claude directory containing BMAD configuration.
Terminal accessMac Terminal, Windows Terminal, or VS Code integrated terminal.

Instructor-Led: Additional

Bring a laptop with the above installed. The instructor will verify setup during the first 30 minutes. If you run into issues beforehand, contact the instructor.

Self-Guided: Additional

No additional requirements. Start with the Getting Started page and work through at your own pace. The sessions include exact prompts you can copy-paste.
